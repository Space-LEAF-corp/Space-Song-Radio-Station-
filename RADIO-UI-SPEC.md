Space LEAF Corp — In‑Vehicle Radio UI Specification
Version 1.0
1. Purpose
Defines the UI/UX behavior of the Car Radio Subsystem (CRS) inside Space LEAF vehicles.

2. UI Principles
Safety‑first

Minimal distraction

Clear emergency signaling

Kids‑Safe visibility

Fleet policy transparency

3. UI Components
3.1 Channel Selector
Scrollable list

Safety tags visible

Kids‑Safe channels highlighted

Restricted channels hidden

3.2 Now Playing Panel
Track name

Artist

Safety level

Region

Bitrate indicator

Satellite/ground source indicator

3.3 Emergency Banner
Full‑width red banner

Emergency type (E1–E5)

Countdown timer

Lockout indicator

3.4 Kids‑Safe Badge
Green badge

Indicates restricted mode

Shows allowed content categories

3.5 Connectivity Indicator
Ground

Satellite

Offline cache

Error state

4. UI States
Normal Mode
Full controls

All channels visible

Kids‑Safe Mode
Restricted channels hidden

Badge visible

Controls limited

Emergency Mode
Lockout

Emergency banner

No channel switching

Offline Mode
Cache playlist only

Connectivity warning

5. Accessibility Requirements
High‑contrast emergency colors

Large tap targets

Voice‑safe interactions

No distracting animations during driving
